# attention-schema

Исследовательский стенд по теории схемы внимания Майкла Грациано. Агент управляет ограниченным ресурсом внимания, строит упрощённую модель этого внимания и использует её для управления и отчёта. Стенд проверяет управляющую функцию схемы и её причинную роль. Наличие феноменального опыта он не устанавливает.

- `docs/spec.md` – техническое задание и сводка теории, сверенная с первоисточниками.
- `docs/results.md` – результаты экспериментов.
- `web/` – реализация на TypeScript.
- `rust/` – вторая реализация с побайтной сверкой выводов.

## Запуск `web/`

Нужен Node.js 22.18 или новее.

```sh
cd web
npm install
npm run typecheck
npm test
```

Эксперименты:

```sh
npm run level0:check   # уровень 0: ручные проверки среды
npm run level0:train   # уровень 0: обучение DQN
```
